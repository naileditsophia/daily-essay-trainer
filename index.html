금융 논술 훈련 트레이너 — 쓰고, 채점받고, 고쳐 쓰고, 성장을 기록합니다

📌 금융감독원 보도자료(fss.or.kr)의 최신 이슈를 웹 검색으로 가져와 매일 논술 주제 2개를 만듭니다. 각 주제에는 논술에 응용할 수 있는 관련 신문기사 1건이 함께 제공됩니다. 하루에 한 번만 생성되며, 같은 날 다시 열면 저장된 주제를 보여줍니다.

주제 생성과 채점에 사용됩니다. 키는 이 브라우저(localStorage)에만 저장되며 외부로 전송되지 않습니다. 키 발급: console.anthropic.com → API Keys

⚠ 주제 생성에는 웹 검색 도구가 사용되어 일반 호출보다 API 요금이 조금 더 발생합니다(회당 수십 원 수준). 채점은 웹 검색 없이 진행됩니다.
💾 훈련 기록은 이 브라우저의 localStorage에 저장됩니다. 브라우저 데이터를 삭제하면 기록이 사라지니 주의하세요.
